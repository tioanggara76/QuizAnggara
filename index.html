Panduan Upload ke GitHub Pages
1. Struktur Folder Repositori
quiz-smk-app/
│
└── index.html       (File tunggal gabungan seluruh kode ini)
2. Langkah-Langkah Deploy Link Publik Gratis
  1. Buat repositori publik baru di GitHub.com (misalnya diberi nama kuis-smk).
  2. Upload file index.html ini ke dalam repositori tersebut.
  3. Buka tab Settings > Pages.
  4. Di bawah menu Build and deployment / Branch, pilih main dan folder / (root), lalu klik Save.
  5. Tunggu sekitar 1 menit, GitHub akan memberikan link publik kuis Anda:
    https://username.github.io/kuis-smk/
